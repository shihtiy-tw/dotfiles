# AWS Configuration

## Highlights
- **Amazon Q Integration**: helper scripts/config for Amazon's coding assistant.
- **CLI Configuration**: Base settings for the AWS CLI.

## Structure
- `config`: Standard AWS CLI config file.
- `amazonq/`: Specific configurations for Amazon Q (formerly CodeWhisperer).

## Installation
The root `make install` script handles the setup of AWS CLI tools.
```bash
make aws
```
