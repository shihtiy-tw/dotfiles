# Alacritty Configuration

## Highlights
- **Speed**: Minimalist configuration for one of the fastest available terminal emulators.
- **YAML Config**: Uses the standard `alacritty.yml` format (note: newer Alacritty versions may use TOML, ensure compatibility).

## Structure
- `alacritty.yml`: Main configuration file.

## Installation
Symlinked to `~/.config/alacritty/alacritty.yml` (or `.toml` depending on version) via `make init`.

## Key Features
- **GPU Acceleration**: Exploits OpenGL for high performance.
- **Simple Config**: No plugin system, just pure configuration.
